# Presentation Script: AEGIS Crisis Orchestration Demo
**Presented by Team: DNA Paradox**  
**Target Duration: 3:45 - 4:00 Minutes (Script Timing: 3m 50s)**  
**Goal**: Explain the Problem, Solution, Features, and Demo so judges understand the project entirely.

---

## ⏱️ Target Timing Breakdown
- **0:00 - 0:35 (35s) | The Problem**: Why emergency systems fail (human latency, rules rigidity, or unsafe LLM hallucinations).
- **0:35 - 1:05 (30s) | The Solution**: The AEGIS hybrid model (deterministic constraints + LLM reasoning).
- **1:05 - 1:50 (45s) | Demo Phase 1**: Nominal run of Variant B, strategy generation, and scores.
- **1:50 - 2:25 (35s) | Demo Phase 2**: Anomaly injection (Bridge Collapse) and real-time detour adaptation.
- **2:25 - 2:55 (30s) | Demo Phase 3**: Failsafe halt (Variant C) showing safety and budget constraint blocks.
- **2:55 - 3:40 (45s) | Architecture**: 25-agent chart, active/future nodes, Refinement Loop, and Constraint Loop.
- **3:40 - 3:50 (10s) | Outro**: Summary and team wrap-up by DNA Paradox.
